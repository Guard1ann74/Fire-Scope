# Fire Scope — контекст для Claude Code

Сервис мониторинга природных пожаров для Краснодарского края и Адыгеи: термоточки
NASA FIRMS → отсев техногенных источников → события → гарь только вокруг
подтверждённого огня по паре Sentinel-2 до/после (физическое правило dNBR по типу
покрова) → проверки и оценка надёжности. Плюс мониторинг районов с оповещениями и
погода в очаге. Показывается отраслевым экспертам. Работаем в PyCharm на Windows.

## Прочти сначала

1. `README.md` — что делает сервис, что проверено, ограничения.
2. `docs/TECHNICAL_CHANGES.md` — журнал всех технических изменений с цифрами,
   включая неудачи и отклонённые идеи. Перед новой идеей проверь, не пробовали ли.
3. `service/README.md` — установка, параметры, REST API.

## Правила работы

- **Никаких моков и выдуманных данных.** Всё, что показывает сервис, — из реальных
  источников; если источник недоступен, сервис честно это говорит.
- **Каждое техническое изменение — в `docs/TECHNICAL_CHANGES.md`** новым разделом с
  датой: что, как, почему, что удалено, файлы и параметры, как проверено, цифры.
  Прошлые разделы не переписываются, а дополняются пометкой «уточнено».
- **Сначала измерить, потом включать.** Пороги — из физики, на проверочных случаях не
  подбираются. Независимая проверка — 20 пожаров Copernicus CLMS
  (`scripts/validate_bs_clms.py evaluate --tag …`), реальные случаи
  (`configs/demo_cases.yaml`, `scripts/warm_demo_cases.py`) — для показа. До и после —
  в одних таблицах; сбойные из-за сети пожары пересчитываются в обоих прогонах.
- При любом изменении расчёта повышай `RESULT_VERSION` в `service/fire_first.py`.
- **Секреты** — только из переменных окружения или `.secrets/*.env` (каталог в
  `.gitignore`); никогда не печатать, не коммитить, не класть в тесты и отчёты.
- Коммит и публикация — только по просьбе пользователя.

## Команды

- Тесты: `.venv/Scripts/python.exe -m unittest discover -s tests` (без сети).
- Запуск: `.venv/Scripts/python.exe -m service`, `FIRES_MONITOR=0` — без фонового опроса.
- Путь проекта содержит кириллицу: GDAL (rasterio) не открывает по нему сертификаты
  `certifi` для сетевого чтения — нужна копия `cacert.pem` по латинскому пути в
  `GDAL_CURL_CA_BUNDLE` (см. журнал, раздел 8).
